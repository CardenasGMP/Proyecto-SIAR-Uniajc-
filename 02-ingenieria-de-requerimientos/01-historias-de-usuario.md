# HISTORIA DE USUARIO:

Las historias de usuario describen las necesidades de las personas que utilizarán SIAR. Cada historia sigue la estructura «Como..., quiero..., para...» e identifica el usuario, la función que necesita y el beneficio que espera obtener.

Estas historias se elaboraron a partir de los requerimientos funcionales definidos en el documento del proyecto y sirven como base para orientar el análisis, el diseño y el desarrollo del sistema.

**HU-01** Como administrador, quiero registrar, editar y eliminar usuarios para mantener actualizada la información del personal del restaurante.

**HU-02** Como administrador, quiero asignar roles a los usuarios para controlar las funciones a las que puede acceder cada persona.

**HU-03** Como usuario del sistema, quiero iniciar sesión para acceder a las funciones correspondientes a mi rol.

**HU-04** Como usuario registrado, quiero recuperar mi contraseña para volver a ingresar al sistema cuando no recuerde mis datos de acceso.

**HU-05** Como administrador, quiero crear, modificar y eliminar productos para mantener actualizado el menú del restaurante.

**HU-06** Como administrador, quiero categorizar los productos para organizar adecuadamente el menú.

**HU-07** Como administrador, quiero gestionar la disponibilidad de los productos para indicar cuáles pueden ofrecerse a los clientes.

**HU-08** Como administrador, quiero crear y modificar mesas para mantener actualizada la información de los espacios de atención.

**HU-09** Como mesero, quiero consultar el estado de las mesas para conocer cuáles se encuentran disponibles.

**HU-10** Como mesero, quiero reservar y liberar mesas para organizar la atención de los clientes.

**HU-11** Como mesero, quiero crear pedidos y agregar productos para registrar las solicitudes de los clientes.

**HU-12** Como mesero, quiero modificar o cancelar pedidos para mantener actualizada la información de la atención.

**HU-13** Como mesero, quiero enviar los pedidos a cocina para que puedan ser preparados.

**HU-14** Como usuario autorizado, quiero consultar el estado de los pedidos para conocer si están Pendientes, En preparación, Listos, Entregados o Facturados.

**HU-15** Como cajero, quiero generar facturas, calcular impuestos y aplicar descuentos para obtener el valor correspondiente a la venta.

**HU-16** Como cajero, quiero registrar el pago y emitir el comprobante para dejar constancia de la transacción.

**HU-17** Como administrador, quiero consultar las ventas por periodo y los productos más vendidos para conocer el comportamiento de las ventas.

**HU-18** Como administrador, quiero consultar el consumo de inventario y la ocupación de las mesas para conocer el uso de los recursos del restaurante.

**HU-19** Como administrador, quiero consultar los indicadores financieros para revisar la información financiera del restaurante.
